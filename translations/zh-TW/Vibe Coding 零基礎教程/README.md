## 什麼是 Vibe Coding？

簡單來說，**Vibe Coding 就是用白話和 AI 聊天，讓 AI 幫你寫程式碼**。你不需要記住任何語法，只需要把需求講清楚，比如說「幫我做一個記帳頁面」，AI 就能幫你生成。寫程式變得像聊天一樣自然，這就是 Vibe Coding 的魅力。

## 從哪開始學習？

**零基礎新手**

- 第 1 天：讀完基礎必讀，理解 Vibe Coding 並做出第一個作品
- 第 1 ~ 2 週：學習 AI 程式設計工具 + 做幾個簡單專案
- 之後：按需學習經驗技巧和產品變現

**有程式設計基礎**

- 第 1 天：快速過完基礎內容，完成快速上手教學
- 第 1 週：學習主流 AI 程式設計工具，嘗試重構之前的專案
- 之後：重點學習進階技巧，提升對話和上下文管理能力
